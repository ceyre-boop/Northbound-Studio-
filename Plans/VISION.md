# Northbound — the mature agent team (target state)

Where the simple agents are growing toward. Captured with Colin 2026-11-21.
The simple versions built now must grow into this; don't contradict it.

## Autonomy
- Agents run almost everything themselves. Colin taps on only two things, forever:
  **money out** (refunds, paying anyone, spend over a set limit) and
  **legal / firing a client** (legal threats, contracts, dropping a client).
- One more permanent gate by exception: a **brand-new product the Automation
  Builder invents is reviewed by Colin once before any real client gets it.**
- Everything else — selling, quoting, supporting, building, publishing,
  posting publicly as Northbound — the agents do on their own.

## What the agents do every day, on their own
A single **daily cycle** each morning (not always-on), ending in **one digest**:
- **Hunt & qualify new leads** so the pipeline never runs dry.
- **Watch every client's results** and proactively email them improvements.
- **Monitor every live site and automation and self-heal** (roll back / fix
  before the client notices).
- **Mine patterns across clients for new automation product ideas.**

The daily digest shows: money in + pipeline, each client's health & results,
what needs Colin's tap (most urgent first), and what the agents did + spent.

## Buddy — full account manager
Beyond answering client email: regular check-ins, a results report per client,
and flags problems or upsell opportunities before the client asks.

## Growth — dogfooding
Northbound markets itself with its own tools: whatever automation/agent exists
is pointed at Northbound too (the poster posts for Northbound, the lead agent
prospects for Northbound, etc.). Agents post publicly as Northbound on their
own, within account-safety rate limits (reversible to drafts-only if flagged).

## Automation Builder — the product factory
Eventually invents, builds, tests and ships brand-new automation products (sold
to everyone), plus custom per-client ones — with Colin's review before any new
product touches a real client.

## Self-improvement
Agents learn from outcomes (which outreach lines convert, which drafts Colin
rewrites, which prices win) and **auto-adjust within the guardrails** above.

## Scale
Target: **dozens of clients, comfortably** — a Mac mini can likely carry that
for a good while; revisit the cloud when it outgrows one machine.

## Guardrails that never bend (from DECISIONS.md)
Money and legal always Colin's tap; new invented products reviewed first;
AI for clients runs on the API via Northbound's backend, never the Max plan;
no fabricated results; cold email carries address + opt-out; nothing deleted.
